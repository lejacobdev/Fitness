# Student Athlete Companion

A training companion for student athletes aged 13–18. Picks up the athlete's sport,
generates season-aware daily and weekly training, runs a morning readiness check-in,
and coaches toward a specific named skill.

Built to the specification in `docs/BUILD-PLAN.md` (§ references throughout the code
point at that document).

## Non-negotiables

These are architectural, not stylistic. Tests in CI enforce them.

- **Nothing generative, nothing borrowed.** No AI/LLM API. No licensed, scraped or
  imported dataset. No stock or commissioned art. No third-party Swift packages.
  Every sport profile, exercise, drill, illustration and coaching sentence is
  authored in this repo or generated by code in this repo.
- **Never predicts injury, diagnoses, or advises return to play.** A CI lint bans
  the words *injury*, *risk*, *damage*, *safe* and *unsafe* from every coach-engine
  template (§11, §12, §21).
- **No calorie deficits under 18**, no body composition, no progress photos, in any
  tier (§13).
- **Works fully offline.** Every daily action — check-in, plan, logging, Watch —
  completes in airplane mode from a cold launch. Only purchases need the network (§3).
- **Minimum age 13.** Date-picker age gate before any account exists (§2).

## Layout

| Path | What |
|---|---|
| `app/` | iOS + watchOS sources and `project.yml` (XcodeGen; the `.xcodeproj` is never committed) |
| `app/Shared/Sources` | Model, engines and generated catalogue code shared by all four targets |
| `backend/` | Node 20 / Express / Prisma / PostgreSQL. Does exactly four things (§3) |
| `content/` | Authoring source for the catalogue, plus the codegen that emits Swift and content packs |
| `tools/` | App Store Connect API scripts (no SDK, see §19) |
| `docs/` | Build plan, privacy policy, review notes |

## Building

There is no Mac in this project's toolchain, so **GitHub Actions on `macos-26` is the
only Swift compiler** (§19). Everything HTTPS-only runs on `ubuntu-latest`.

```bash
# Content catalogue + codegen + integrity tests (Linux)
cd content && npm ci && npm test && npm run build

# Backend (Linux)
cd backend && docker compose up --build

# iOS: dispatch CI, there is no local path
gh workflow run check.yml         # XcodeGen, unsigned build, §21 checks, screenshots
gh workflow run testflight.yml    # archive, export, upload, print entitlement evidence
gh workflow run packs.yml         # regenerate content packs, verify checksums
gh workflow run asc-inspect.yml   # read-only App Store Connect inspection
```

`gh workflow run` returns 404 for a minute or two after a workflow file is first
pushed. Retry; it is not broken (§19).

Generated code (`app/Shared/Sources/Generated/`) and content packs (`content/dist/`)
are not committed — `content/scripts/build.mjs` produces them and CI runs it before
any Xcode build.
